## GitHub display notes

- The README uses standard HTML `<img>` elements with direct HTTPS image URLs, which GitHub supports in repository Markdown.
- The head-unit image is stored inside this repository. The remote, ESP32-C3, and USB cable photos are loaded from their publishers, so their display still depends on those publishers keeping the image URLs available and permitting external embedding.
- These are representative product photographs; they do not confirm the exact model of each physical component used in the project.
- A public image appearing in a search result does **not** automatically mean it is licensed for redistribution. Check each source's copyright and licensing terms and obtain permission where required.
